# El Desarmador Landing Page

Landing page oficial versión 1.0 para **El Desarmador**, ferretería ubicada en Huamuxtitlán, Guerrero, México.

**Slogan:** Tu herramienta de cada día  
**Unidad comercial de:** OBREXA

## Objetivo

Crear una página pública, sencilla, rápida y profesional para que clientes locales puedan:

- Conocer la ferretería.
- Ver productos y categorías.
- Consultar horarios.
- Encontrar ubicación.
- Contactar por WhatsApp.
- Solicitar cotizaciones.

## Tecnología

Este proyecto usa:

- HTML
- CSS
- Google Fonts: Montserrat y Lato

No usa frameworks, librerías pesadas, React, carrito de compra ni pagos en línea.
