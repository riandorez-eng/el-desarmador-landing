# El Desarmador Landing Page

Landing page oficial versión 1.1 para **El Desarmador**, ferretería familiar nacida en Huamuxtitlán, Guerrero, México.

**Slogan:** Tu herramienta de cada día  
**Posicionamiento:** Ferretería familiar nacida en Huamuxtitlán, con soluciones para casa, campo y obra.

## Objetivo

Crear una página pública, sencilla, rápida y profesional para que clientes locales puedan:

- Conocer la ferretería y su historia familiar.
- Ver a quién atiende El Desarmador.
- Consultar categorías de productos.
- Conocer el compromiso y valores de la tienda.
- Consultar horarios.
- Encontrar ubicación.
- Contactar por WhatsApp.
- Solicitar cotizaciones o revisar disponibilidad.

## Enfoque público v1.1

La versión 1.1 comunica a El Desarmador como una ferretería familiar nacida en Huamuxtitlán, con trato respetuoso, atención cercana y soluciones para casa, campo y obra.

La landing pública todavía no menciona OBREXA. Esa integración queda reservada para una etapa futura.

Google Maps se mantiene como pendiente; no se debe inventar enlace.

## Tecnología

Este proyecto usa:

- HTML
- CSS
- Google Fonts: Montserrat y Lato

No usa frameworks, librerías pesadas, React, Supabase, formularios conectados, carrito de compra ni pagos en línea.

## Publicación en Netlify

El sitio sigue siendo compatible con Netlify como sitio estático:

- Build command: vacío
- Publish directory: `.`
